# 🛠️ resourcpack_leer (1.21.11)

Enthält alle Standard-Texturen der Minecraft Version 1.21.11. Perfekt als Basis für eigene Projekte! 🎨

---

## 📥 Installation

1. Lade den Ordner als **.zip** herunter. 📂
2. **WICHTIG:** Du musst die Datei entpacken, bis du den Ordner `resourcpack2026-main` siehst. (Die Datei wurde beim Download von GitHub "doppelt gezippt"). 📦📦
3. Kopiere den Ordner in deinen `resourcepacks` Ordner von Minecraft. 🎮
4. Aktiviere es im Spiel unter Optionen. ✅
