# resourcpack_leer
Enthält alle Dateien standart texturen. von der Minecraft version 1.21.11 .

Dieses Resource Pack ist für Minecraft 1.21.11 optimiert.
Hier findest du alle Texturen für mein Projekt.

## Installation
1. Lade den Ordner als .zip herunter.
2. Kopiere die .zip in deinen `resourcepacks` Ordner.
3. Aktiviere es im Spiel.
4. man muss 2 mal entpacken (:bis zu resourcpack2026-main
5.WEil die datei 2mal gezippt wurde (:
